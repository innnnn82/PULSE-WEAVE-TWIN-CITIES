# 六百年的手，认得这座城吗？

*Do Six-Hundred-Year-Old Hands Still Know this City?*

MagicBrush 为上海张江双塔 LED 外立面创作的灯光影像。作品将石库门、崇明土布、徐行草编、上海绒绣、海派剪纸和水墨转化为十二组可独立循环的视觉单元。

创作团队为徐娴（Xian Xu）、徐婷（Ting Xu）、林子煊（Zixuan Lin）。MagicBrush 获小红书最受公众欢迎奖（Xiaohongshu People's Choice Award，团队奖）。

[双语作品页、展演现场与东塔影片](https://innnnn82.github.io/PULSE-WEAVE-TWIN-CITIES/) · [小红书项目链接](https://xhslink.cn/o/5YzgPGJzHIW)
